## Token Configuration

### Required Tokens

| Service | Environment Variable | How to Get |
|---------|---------------------|------------|
| GitHub API | `GITHUB_PERSONAL_ACCESS_TOKEN` | [github.com/settings/tokens](https://github.com/settings/tokens) → Generate new token → Select `repo`, `workflow` scopes |

### Setting Up Tokens

```bash
# Option 1: Export in shell
export GITHUB_PERSONAL_ACCESS_TOKEN="ghp_xxxxxxxxxxxx"

# Option 2: Add to ~/.zshrc or ~/.bashrc
echo 'export GITHUB_PERSONAL_ACCESS_TOKEN="ghp_xxxxxxxxxxxx"' >> ~/.zshrc

# Option 3: Use .env file (add to .gitignore!)
echo 'GITHUB_PERSONAL_ACCESS_TOKEN=ghp_xxxxxxxxxxxx' >> .env
```

## Troubleshooting

### MCPs not loading

1. Check if MCPs are properly configured in `.mcp.json`
2. Verify npm packages can be installed: `npx -y @upstash/context7-mcp`
3. Check Claude Code logs for errors

### Skills not appearing

1. Verify skill files exist in `.claude/skills/`
2. Each skill should have a `SKILL.md` file
3. Restart Claude Code session

### Commands not working

1. Check command files in `.claude/commands/`
2. Ensure proper markdown frontmatter
3. Commands start with `/`
